About this project

This dashboard is modeled on the third-party monitoring (TPM) trackers I helped design and ran with the TPM team as Senior Data Systems and M&E Advisor at Management Systems International (2022 to 2025) for USAID-funded health, education, agriculture and governance programs across 34 provinces. In that role, field monitors submitted site-visit data in Survey123, my Python pipeline cleaned and validated it, and Power BI dashboards with row-level security showed yellow and red flags to mission leadership.

The pipeline cut monthly processing from about 20 analyst hours to 8 (around 60 percent). The tracker covered thousands of visits across more than 40 awards.

How this sample version is built

  • Raw export to clean table: clean_tpm.py fixes province spellings (for example "Saripul", "Sar-e-Pul", "SAR-E POL" all become "Sar-e Pol"), mixed date formats and status labels, removes duplicate visits and writes a QA log of rule violations.
  • Star schema and queries: tpm_model.sql defines the fact and province tables and holds the queries behind each visual (completion by region, flag rate by office, 3-month rolling trend, provinces above the national red-flag rate, partners with repeated red flags).
  • Power BI measures: measures.dax holds the same KPIs I used in the original Power BI tracker (Planned, Completed, IP Postponed, IP Canceled, % of each, flag rates, rolling trend), ready to paste into a Power BI model built on these CSV files.
